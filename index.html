About this experiment +

The live session computes a fresh run of the full FlyWire v783 connectome: 139,255 neurons and 15,091,983 connected pairs. Neurons use the repository’s leaky integrate-and-fire model at 0.1 ms steps. Letters are assigned to the 90 × 30 mm arena’s 3 × 9 grid by a seeded permutation. Saved 300-second recordings remain available in the session menu.

The fly walks at a base speed of 8 mm/s. Nearby walls send proximity-scaled Poisson input to the eye’s LC4 + LPLC2 looming detectors; the network drives turning neurons on the opposite side, steering the fly away. Turning rates use a 50 ms window. The giant-fiber escape signal is recorded but does not control walking.

Randomness comes from the injected Poisson inputs. The brain’s wiring shapes that noise. Each live session uses a fresh random seed; its path and keystrokes are computed as it runs. The browser uses its own seeded random-number generator, so its seed values do not reproduce the Python recordings. The hovering artwork depicts the model’s walking trajectory and is enlarged for visibility.
