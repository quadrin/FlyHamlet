03 Protocol & scientific limits+

Task. Present t or o for 100 ms, wait 25 ms with no cue, then present t or o for another 100 ms. Input stops at 225 ms. All four ordered pairs are balanced separately in training and evaluation, with independent noise. The same pair order and neural-noise seeds are used across conditions. Each trial starts at rest; no reset occurs between its letters.

What is measured. At the final cue step and 25, 100 and 200 ms after input off, read only the current state of nonstimulated neurons. Each neuron’s membrane voltage relative to rest and its synaptic current are rounded to the nearest 0.01 mV before 128 fixed pools report their means. All annotated eye cells are excluded. The rounding keeps microvolt-scale floating-point remnants, which can stay frozen in the float32 model, out of the decoders. No earlier snapshot, cue label, trial index, clock, or previous output is a feature.

What learns. For each condition and snapshot, one scaler with training-only means and standard deviations and two ridge classifiers, one per position, are fitted on 64 training trials, then frozen. Both positional classifiers receive the same standardized snapshot. The external readout knows there are two output positions. This is supervised state decoding, not spontaneous sequential recall; the fly is an illustration.

Slower dynamics. The hypothesis condition multiplies the membrane and synaptic time constants by 10 and every signed synaptic weight by 0.1, so each synaptic event keeps its integrated voltage response while its peak falls. Conduction delay, refractory period and thresholds are unchanged. It uses the same graph topology and weight signs. These parameters are imposed by the experimenter; they are not identified from fruit-fly memory data. The reset control uses the same slower model and identical cues, then clears all neural state at input off, so its post-cue snapshots are exactly rest. Background drive is off in every condition.

Interpretation. Exact-pair success must be read alongside both positional scores, uncertainty and the reset control. A 50% exact-pair result can be explained by retaining only the final letter and guessing the first. The final-cue-step diagnostic is read while input is still on, before any reset, and is never combined with post-cue snapshots. Delayed state decoding does not establish biologically accessible memory, plasticity, or a benefit of anatomical wiring. An improved result under slower dynamics concerns that hypothetical model.

Reproducibility. Export the complete protocol, both neural parameter sets, raw quantized pool measurements, scalers, frozen readouts, predictions, input timing, seeds and graph hashes. All errors are retained. New loads default to 1×; actual simulation speed depends on the device. The first run downloads about 49 MB and then prepares the rescaled comparison network.
